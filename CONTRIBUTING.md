# Contributing to LinkedIn Optimizer Pro

Thank you for your interest in improving LinkedIn Optimizer Pro! We welcome contributions that align with our **"Extreme Minimalist"** philosophy.

## 🛠️ Development Principles
1.  **Single-Source UI**: Keep complexity within `src/app/page.tsx` using raw Tailwind. Avoid unnecessary folder nesting.
2.  **Performance First**: Ensure animations (Framer Motion) remain smooth and don't block the main thread.
3.  **Local Logic**: Enhance the internal scoring engine in `src/lib/scoring-engine.ts` for offline reliability.

## 🤝 How to Contribute
1.  **Fork** the repository.
2.  **Create a Branch** (`git checkout -b feature/amazing-feature`).
3.  **Commit Changes** (`git commit -m 'Add amazing feature'`).
4.  **Push** to the branch (`git push origin feature/amazing-feature`).
5.  **Open a Pull Request**.

## ⚖️ Note on Style
Please maintain the **Instrument Serif / Inter** typography pairing and the **#F2EFED** background palette for consistency.
